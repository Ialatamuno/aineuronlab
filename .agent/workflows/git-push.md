// turbo-all
After making any code changes, always run these commands from the project root `c:\Users\TOBI\Documents\aineuronlab`:

1. Stage all changes:
```
git add -A
```

2. Commit with a descriptive message summarizing the changes made:
```
git commit -m "<short description of changes>"
```

3. Push to remote:
```
git push
```
